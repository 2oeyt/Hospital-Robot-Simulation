# Hospital-Robot-Simulation

โปรเจกต์นี้เป็นโปรแกรมจำลองการทำงานของหุ่นยนต์ภายในโรงพยาบาล พัฒนาด้วยภาษา C++ โดยประยุกต์ใช้หลักการ Object-Oriented Programming (OOP) และแสดงผลการจำลองผ่าน Terminal ในรูปแบบตารางขนาด 10 × 5 ช่อง

ระบบประกอบด้วยหุ่นยนต์ 3 ตัว แบ่งเป็น 2 ประเภท ได้แก่

DeliveryRobot (2 ตัว): หุ่นยนต์สำหรับส่งยาไปยังห้องผู้ป่วย

CleanerRobot (1 ตัว): หุ่นยนต์สำหรับทำความสะอาดห้องผู้ป่วย

ระบบมีงานทั้งหมด 5 งาน แบ่งเป็นงานส่งยา 3 งาน และงานทำความสะอาด 2 งาน โดยหุ่นยนต์จะรับงานตามประเภทและระดับความสำคัญ (Task Priority) เคลื่อนที่ทีละ 1 ช่องต่อ Timestep และทำงานตามระยะเวลาที่กำหนด

โปรแกรมจะแสดงตำแหน่ง สถานะ แบตเตอรี่ และความคืบหน้าของงานในแต่ละ Timestep พร้อมสรุปผลเมื่อทุกงานเสร็จสิ้น

# Project File
RobotClasses.h — ประกาศคลาส Attributes และ Methods

main.cpp — เขียนฟังก์ชันการทำงานของคลาส กำหนดสถานการณ์จำลอง และ int main()

tests.cpp — Unit Tests และตัวอย่าง Change Request
